# Chapter 7: Rendering Countless Blades of Waving Grass
> 저자: Kurt Pelzer (Piranha Bytes)

## 핵심 개념
- **해결하려는 문제**: 넓은 지형에 풀밭을 GPU 효율적으로 렌더링하면서 바람에 흔들리는 애니메이션까지 구현
- **교차 쿼드(Cross Quads)**: 개별 풀잎을 폴리곤으로 모델링하는 대신, 3개의 교차하는 쿼드로 "풀 오브젝트"를 구성해 적은 폴리곤으로 조밀한 풀밭 표현
- **알파 텍스처**: 풀잎 텍스처에 알파 채널을 사용해 개별 풀잎 형태를 표현
- **Vertex Shader 애니메이션**: 풀의 바람 흔들림을 vertex shader에서 계산 (3가지 방법)
- **LOD 및 배치 최적화**: 적은 draw call로 넓은 영역을 커버하는 전략

## 기술적 세부사항

### 풀 텍스처 준비
1. 개별 풀잎을 3D로 모델링 & 렌더링
2. 여러 풀잎을 하나의 텍스처에 배치 (다양한 높이, 방향, 색상)
3. 알파 채널로 풀잎 실루엣 정의 → 알파 테스트로 배경 제거
4. 밝기 그라데이션: 아래쪽 어둡게, 위쪽 밝게 → 자연스러운 자체 그림자 근사

### 풀 오브젝트 구성 (Cross Quads)
- **3개의 교차 쿼드**를 별 모양으로 배치 (60° 간격)
- 어느 각도에서도 조밀해 보임 (단일 평면은 측면에서 사라짐)
- Back-face culling 비활성화 → 양면 렌더링
- 하나의 풀 오브젝트 = 6개 삼각형 (12 정점)으로 수십 줄기의 풀잎 표현

### 3가지 애니메이션 방법

**1. 버텍스 위치 기반 애니메이션**
- 각 정점의 월드 위치를 기반으로 바람 오프셋 계산
- 장점: 하나의 draw call로 전체 초원 렌더링, 부드러운 바람 파동
- 단점: 같은 오브젝트 내 정점이 다르게 움직여 텍스처 왜곡 발생

**2. 그래스 오브젝트 기반 애니메이션**
- 각 풀 오브젝트의 **중심 위치**를 기반으로 동일한 오프셋 적용
- 중심 위치를 텍스처 좌표로 전달 (vertex format에 추가)
- 장점: 오브젝트 내 일관된 변형 + 인접 오브젝트 간 다른 움직임 → 국소적 혼란(local chaos)

**3. 인스턴싱 기반 애니메이션**
- 동일한 메시를 여러 인스턴스로 복제, 인스턴스별로 다른 바람 위상 적용
- draw call 수 절감

### 바람 계산 (Vertex Shader)
```
// 정점이 풀잎의 아래쪽(고정)인지 위쪽(흔들림)인지 구분
// 텍스처 좌표의 y값 사용: y=0 아래쪽, y=1 위쪽
offset = sin(time + position.x * freq) * windStrength
vertex.x += offset * texcoord.y  // 위쪽만 이동
```

## 수식 및 알고리즘

**바람 오프셋 함수:**
$$offset(P, t) = A_{wind} \cdot \sin(\omega \cdot (P_x + P_z) + \varphi \cdot t)$$

**정점 변형 (위쪽 정점만):**
$$P'_x = P_x + offset \cdot v_{texcoord.y}$$
$$P'_z = P_z + offset_z \cdot v_{texcoord.y}$$
- $v_{texcoord.y}$: 0(아래) ~ 1(위)로 변형 강도 제어

**풀 오브젝트 기반 변형:**
$$offset = f(center_{xz}, t)$$
모든 정점에 동일한 offset 적용 → 텍스처 왜곡 없음

## UE5 관점에서의 활용
- **Foliage System**: UE5의 폴리지 시스템은 인스턴싱 기반으로 수십만 개의 풀 메시를 배치. 이 챕터의 인스턴싱 접근의 대규모 확장판.
- **Nanite**: UE5.1+에서 Nanite 폴리지 지원. LOD 자동 처리로 매우 상세한 풀 메시 가능.
- **World Position Offset**: 바람 애니메이션은 UE5 머티리얼의 World Position Offset으로 구현. SimpleGrassWind 노드가 기본 제공됨.
- **Procedural Foliage**: PCG(Procedural Content Generation) 시스템으로 풀밭 배치 자동화 가능
- **현대적 대안**: 개별 풀잎을 메시로 렌더링 + Nanite가 가능해짐. 교차 쿼드 방식은 여전히 저사양에서 유효.

## 핵심 요약 (3줄)
- 3개의 교차 쿼드 + 알파 텍스처로 적은 폴리곤으로 조밀한 풀밭을 표현하는 기법이다.
- Vertex shader에서 바람 애니메이션을 계산하며, 오브젝트 중심 기반 방식이 품질/효율 균형이 가장 좋다.
- 이 교차 쿼드 + 셰이더 바람 방식은 현대 게임 엔진 풀밭 렌더링의 기본 원리로 여전히 사용된다.
