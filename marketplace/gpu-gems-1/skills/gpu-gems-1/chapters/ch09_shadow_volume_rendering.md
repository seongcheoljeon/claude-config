# Chapter 9: Efficient Shadow Volume Rendering
> 저자: Morgan McGuire (Brown University)

## 핵심 개념
- **해결하려는 문제**: 스텐실 버퍼 기반 섀도우 볼륨을 효율적으로 구현해 실시간 그림자 생성 (Doom 3에서 사용된 기법)
- **섀도우 볼륨 원리**: 실루엣 엣지에서 빛 반대 방향으로 볼륨을 확장(extrude) → 스텐실 버퍼에서 그림자/비그림자 픽셀 분류
- **Z-Pass vs Z-Fail**: 카메라가 섀도우 볼륨 내부에 있을 때의 처리 전략
- **멀티패스 렌더링**: 각 광원마다 섀도우 볼륨 렌더링 + 조명 패스를 반복
- **기하/필레이트 최적화**: 실루엣 감지, 유한 볼륨, 시저 클리핑 등 다양한 최적화 기법

## 기술적 세부사항

### 프로그램 구조
1. **Ambient Pass**: 전역 앰비언트 + 깊이 버퍼 확립
2. **각 광원에 대해 반복**:
   a. 실루엣 엣지 감지 (CPU)
   b. 섀도우 볼륨 렌더링 → 스텐실 버퍼에 그림자 마크
   c. 조명 패스: 스텐실 테스트 통과한 픽셀만 조명 추가
3. 모든 광원의 결과를 additive blending으로 합산

### 실루엣 엣지 감지
- 엣지의 두 인접 면 중 하나가 앞면, 다른 하나가 뒷면이면 → **실루엣 엣지**
- `backface[edge.face[0]] != backface[edge.face[1]]`
- 와인딩 순서를 일관되게 유지해야 함

### 섀도우 볼륨 구성
1. 실루엣 엣지의 정점들을 빛 반대 방향으로 무한대까지 확장 → 사이드 쿼드
2. **Light Cap**: 원래 메시의 앞면 (빛을 향한 면)
3. **Dark Cap**: 원래 메시의 뒷면을 무한대로 투영한 것
4. Vertex Shader에서 w=0으로 설정해 무한대 확장 구현

### Z-Pass vs Z-Fail
- **Z-Pass**: 깊이 테스트 통과한 면만 카운트. 빠르지만 카메라가 볼륨 내부일 때 실패
- **Z-Fail (Carmack's Reverse)**: 깊이 테스트 실패한 면을 카운트. 항상 정확하지만 dark cap 필요 → 더 많은 지오메트리
- 실전: 카메라가 볼륨 외부면 Z-Pass, 내부면 Z-Fail로 전환

### 주요 최적화
- **방향 광원**: 모든 정점이 같은 방향으로 수렴 → dark cap 불필요, 쿼드 대신 삼각형
- **유한 볼륨**: 점 광원의 범위 구체 내로 확장 제한 → 필레이트 절감
- **시저 클리핑**: 광원 범위의 2D 바운딩 박스로 스텐실/조명 렌더링 영역 제한
- **깊이 바운드 테스트**: 깊이 범위 제한으로 불필요한 스텐실 업데이트 방지
- **실루엣 최적화**: 인접 면의 법선이 유사하면 엣지 제거 가능

## 수식 및 알고리즘

**실루엣 엣지 판정:**
$$isSilhouette(e) = (N_{face0} \cdot L > 0) \neq (N_{face1} \cdot L > 0)$$

**무한대 확장 (Vertex Shader):**
$$P_{extruded} = \begin{cases} P & \text{if front-facing (w=1)} \\ P - L \times \infty & \text{if back-facing (w=0)} \end{cases}$$
- w=0으로 설정하면 perspective divide에서 자동으로 무한대 방향

**스텐실 연산 (Z-Fail):**
```
앞면: 깊이 실패 시 stencil++
뒷면: 깊이 실패 시 stencil--
결과: stencil != 0 → 그림자 안
```

## UE5 관점에서의 활용
- **역사적 의의**: 섀도우 볼륨은 Doom 3 시대의 핵심 기술이었지만 현대 엔진에서는 거의 사용 안 함
- **Shadow Maps 대세**: UE5는 Cascaded Shadow Maps, Virtual Shadow Maps를 사용. 섀도우 볼륨 대비 구현 간단, 알파 테스트 지원, 소프트 섀도우 가능.
- **Virtual Shadow Maps (VSM)**: UE5의 VSM은 Nanite와 연동해 매우 상세한 그림자를 단일 큰 가상 텍스처로 관리
- **섀도우 볼륨의 장점**: 픽셀-정확한 하드 섀도우. 특수 목적(정확한 접촉 그림자 등)에서 여전히 가치 있음.
- **Ray Traced Shadows**: Lumen/하드웨어 RT로 정확한 그림자 가능. 섀도우 볼륨의 정확성 + 섀도우 맵의 편의성.

## 핵심 요약 (3줄)
- 스텐실 버퍼 기반 섀도우 볼륨으로 픽셀-정확한 실시간 그림자를 생성하는 체계적 구현 방법을 다룬다.
- Z-Pass/Z-Fail 전략, 실루엣 감지, 무한대 확장 등 핵심 알고리즘과 다양한 최적화 기법을 제시한다.
- 현대에는 섀도우 맵이 대세지만, 섀도우 볼륨의 원리는 가시성 판단의 기초 이론으로 여전히 중요하다.
